# HRT.org prelaunch audit — 12 October 2026

**Assessment: not ready for unrestricted launch.** The local audit and repairs are complete. Missing approved content, unsupported legacy workflows, backend delivery verification and unresolved business/clinical statements still prevent a full readiness claim. Nothing was deployed; no external messages, bookings, patient records, orders or payments were created.

Evidence: [searchable screenshot gallery](scraps/prelaunch-2026-10-12/index.html), [route checklist CSV](scraps/prelaunch-2026-10-12/route-checklist.csv), [detailed JSON ledger](scraps/prelaunch-2026-10-12/route-checklist.json). Audit evidence and source/workflow archives are excluded from the publish output.

## Actual coverage

- **306 public HTML files plus 15 query variants = 321 URL cases**, each captured and actually visually reviewed at **1440, 768 and 390 pixels wide**: **963 route/viewport cases**. Viewport height was 900px for main/services and 1000px for articles/support. Coverage includes all main pages and aliases, audience/product variants, 11 services, 182 health articles, Resources and category archives, support/providers/policies, assessments and legacy forms, GLP-1 routes, and 404.
- Chrome **154.0.8037.98** performed the full review. Edge **155.0.4283.45** checked six mobile pages as a supplementary smoke test. These are desktop browsers with emulated viewports; no physical-device, Safari or Firefox testing was performed. Selected main layouts also received 320px checks.
- Full-height screenshots were reviewed through full-page composition sheets and contiguous section montages, supplemented by readable close-ups for affected content and interaction states. This is not a claim of word-by-word clinical/legal proofreading of every article. Stable source captures and refreshed affected-page captures are identified in the ledger; all final published HTML files also receive a separate technical scan.
- Scope reports: [main and service journeys](scraps/prelaunch-2026-10-12/main/REPORT.md), [support/assessment/policy checks](scraps/prelaunch-2026-10-12/content/REPORT.md), [articles and Resources](scraps/prelaunch-2026-10-12/articles/REPORT.md), [technical verification](scraps/prelaunch-2026-10-12/TECHNICAL-REPORT.md).

`npm run build:vercel` and `npm run typecheck` pass. The build prerenders 203 React bodies and emits **306 HTML pages / 874 allowlisted public files**. The final scan checks **839 distinct local file/query/fragment targets**, with no unresolved local targets, metadata failures, empty content roots or detected public secret patterns. All **112 local redirect cases**, **20 query metadata checks** and **14 script-blocked Product initial states** pass. The sitemap has 252 eligible URLs. No JSON-LD, microdata or RDFa is present, so no rich-result eligibility is claimed. Dependency audit reports **zero known vulnerabilities**; no lint or general test script is configured. Pattern scanning is not a penetration test. [Technical evidence](scraps/prelaunch-2026-10-12/technical.json).

The final **18-template × two-width** axe run plus the two affected About reruns report **zero WCAG A/AA violations, page exceptions or document overflow**. Targeted article checks add ten passing cases. These are bounded automated checks with manual keyboard/focus review, not complete assistive-technology or site-wide accessibility certification.

Cold-cache mobile lab runs used **1.6Mbps, 150ms latency and 4× CPU slowdown** on the local uncompressed server. After the About fix, the selected mobile LCP samples span **1.50–3.91 seconds**, with **CLS 0**. About improved from **6.77s to 3.10s**; its mobile hero shrank from 197KB to 66KB. The men's audience view remained the slowest baseline sample at 3.91s (separate repeat 3.77s). Desktop CLS stayed below 0.032. One desktop Home run produced no LCP entry; a controlled repeat measured 0.528s rather than treating the missing entry as zero. These are local lab samples, not production Core Web Vitals or INP measurements. Audience/About should be rechecked with real deployment compression and caching. ## Required before launch

1. **Backend owner: verify deployed assessment/email workflows in an authorized test environment.** Confirm versions, credential bindings, final-origin CORS, payload validation/escaping, abuse/idempotency protection, score fields after Gmail and truthful success after send acceptance. The supplied men's workflow has an incomplete SMTP branch. Existing [inactive repair artifacts](source-content/n8n-review/repairs/README.md) were not imported or activated. Real delivery and patient-system writes were not tested.
2. **Content/workflow owner: supply or retire 26 GLP-1 destinations and two unrecovered legacy forms; verify three restored external handoffs.** All 26 missing GLP-1 official URLs returned HTTP 200 but only an empty navigation/cart shell. Only `glp-1/ozempic-vs-wegovy/index.html` has a complete local article in that set. Nutrition and supplement-intake sources lack a usable original form/scoring/submission contract. ED, weight-loss requests and the distinct legacy menopause quiz now link to recovered official Typeforms; their submission, results and downstream processing remain untested. The old menopause questionnaire differs from the native questionnaire, so it was not substituted into native scoring. These legacy routes remain noindex. Exact evidence is in the [source recovery report](scraps/prelaunch-2026-10-12/content/glp-source-check/report.json) and the scope report.
3. **Business/clinical owner: reconcile current claims and terms.** Supplied service copy says 3–7 business days and consultation at no added cost; testing/product sources include different timing/inclusions. Confirm the inherited men's HRT $100–500/month and peptide $250–600/month FAQs, service availability, clinical/statistical/FDA wording and return terms. Current local policy retains 30 days for eligible unused kits; no unsupported policy standardization was made. Review supplied scoring quirks documented in the assessment report.
4. **Editorial owner: resolve citation gaps.** The men's HRT article has an empty References section. Of 66 external destinations, six remained unreachable and nine remained blocked/challenged; blocked responses do not prove a link is dead. Facebook displays unavailable content, and a USAGov shortlink now reaches a generic homepage. Exact source-route mappings are in [external GET results](scraps/prelaunch-2026-10-12/external-verification.json) and [browser follow-ups](scraps/prelaunch-2026-10-12/external-browser-verification.json). No unsupported replacement citation was invented.
5. **Deployment owner: verify the authorized production deployment.** Actual HTTPS/domain behavior, Vercel edge redirects/headers/caching, real-origin performance, authenticated portal operations, checkout and delivered email remain untested. Add physical mobile/Safari verification. The supplementary external Shop captures also showed occasional missing product images and awkward category-label wrapping; those belong to the external store.

## Prepared deployment configuration

The checked configuration uses `npm run build:vercel` and publishes **dist**. Do not publish the raw workspace. Current output intentionally remains **noindex**. Only an approved Production build with both `VERCEL_ENV=production` and `HRT_ALLOW_INDEXING=true` enables eligible routes; preview builds and unsupported/unavailable routes remain noindex. All three indexing fixture combinations passed. No environment flag was enabled for launch and no deployment was performed.
