Connect AI when you’re ready.

The catalog, service browser, product details and comparisons work without an API key. Natural-language conversation requires a server-side OpenAI key and a verified model.

1. Add your key on the server

Copy .env.example to .env.local in the project folder. Edit it locally:

OPENAI_API_KEY=your_key_here
OPENAI_MODEL=

Keep the model blank until you verify access. Never enter credentials in the chat, browser code, or a public repository. This page does not accept or store keys.

2. Verify your Luna model

Run npm run models. It lists Luna identifiers returned by your account without printing your key. Official documentation lists gpt-6-luna; account access has not been verified in this project.

Set OPENAI_MODEL to the exact verified identifier. There is no automatic model fallback.

3. Restart and test

Run npm start, then ask the guide a question. The first request verifies the configured model with the account. Run the live conversation scenarios in docs/VERIFICATION.md before public release.
